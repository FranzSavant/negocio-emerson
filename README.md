## Los 4 criterios

Todo producto que se compre tiene que cumplir estos cuatro:

| | Criterio | Qué mira |
|:--:|---|---|
| 🪶 | **Liviano** | el rutero lo mueve fácil |
| 📦 | **Compacto / no perecedero** | ocupa poco, no se daña en la ruta |
| 🔄 | **Alta rotación** | consumo diario; el tendero lo recompra solo |
| 💰 | **Margen** | deja plata para la empresa + Emerson + el rutero *(a confirmar con precios)* |
