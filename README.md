# Negocio Emerson

El negocio de Emerson, ordenado en un repositorio. Dos operaciones:

| | Operación | Mi rol | Detalle |
|:--:|---|---|---|
| 🥖 | **Pan dulce** (en marcha) | **Asesor** — ayudo a automatizar | [→ `pan/`](pan/README.md) |
| 📦 | **Distribución** de consumo masivo | **Socio** (reparto y decisión) | [→ `distribuidora/`](distribuidora/README.md) |

🌐 **Enlace público (para compartir):** <https://franzsavant.github.io/negocio-emerson/>

*Última actualización: 2026-10-14.*

---

## Los 4 criterios (para lo que se compre en la distribución)

| | Criterio | Qué mira |
|:--:|---|---|
| 🪶 | **Liviano** | el rutero lo mueve fácil |
| 📦 | **Compacto / no perecedero** | ocupa poco, no se daña en la ruta |
| 🔄 | **Alta rotación** | consumo diario; el tendero lo recompra solo |
| 💰 | **Margen** | deja plata para socios + Emerson + rutero *(a confirmar con precios)* |

## Datos compartidos

La carpeta [`data/`](data/README.md) guarda las planillas (proveedores, precios, clientes, compras, ventas). Sirve a los dos proyectos.

## Cómo está armado

Este repo es el **activo**. Cada proyecto vive en su carpeta con su propio `README.md`. La página web (`index.html`) muestra este contenido y navega entre las carpetas.
